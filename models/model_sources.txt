# Where to find the OpenPose network weights.
#
# THIS REPOSITORY DOES NOT HOST OR REDISTRIBUTE ANY WEIGHTS. This file only records
# locations where they have been published, so that models/getModels.sh can fetch them
# for you. The weights are CMU's work and are covered by CMU's license (see ../LICENSE:
# academic / non-profit, non-commercial use). You are responsible for complying with it.
#
# Format (whitespace separated, one source per line, '#' starts a comment):
#
#   <model>  <sha256 or ->  <url>
#
# - <model> is one of: body25 coco mpi face hand
# - Several lines with the same <model> are mirrors; they are tried top to bottom.
# - Put the real SHA-256 in the second column once you have verified a file. With '-' the
#   script still downloads, but warns that nothing was verified.
#
# Files are saved to:
#   body25 -> pose/body_25/pose_iter_584000.caffemodel
#   coco   -> pose/coco/pose_iter_440000.caffemodel
#   mpi    -> pose/mpi/pose_iter_160000.caffemodel
#   face   -> face/pose_iter_116000.caffemodel
#   hand   -> hand/pose_iter_102000.caffemodel
